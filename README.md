В этом репозитории вся неделя 4: Визуализация по отраслям, GICS и X-Tech, Способы представления и визуальное кодирование, Банки vs финтех, Пять ноутбуков Colab, Этика и итоги.

Читать онлайн: https://adminmrobo.github.io/dv-week4/ru/week4_index.html

Автор · Сансун Ан (Sangsun Ahn), генеральный директор M-Robo Inc.

### Языки

- Переключить язык можно в любой момент — через 🌐 список выбора языка в верхнем меню. Вы останетесь на той же странице и на том же месте, но в другой языковой версии.
- При первом посещении страница автоматически открывает версию на языке браузера (корейскую — если браузер на корейском или на неподдерживаемом языке). Выбранный язык запоминается на этом устройстве.
- Добавьте `?lang=ru` (или ko, en, zh, ja, uz) к адресу страницы, чтобы открыть нужную языковую версию напрямую.
- `index.html` в корне репозитория — экран выбора языка.

### Что есть на каждой странице

- Изложение в форме диалога четырёх персонажей
- Встроенные в страницу схемы, таблицы и примеры кода
- Неделя 4: ссылки на пять блокнотов Colab (открываются прямо со страницы)

Ссылки между страницами и языками работают при указанной структуре папок, поэтому **не переименовывайте файлы и папки.** Этот README — описание репозитория, на сайте он не показывается.

### Данные и изображения

- Изображения персонажей (аватары, в полный рост, выражения лиц) и баннер обложки создал автор.
- Вырезки из слайдов взяты из исходных материалов лекций.
- Некоторые значения — иллюстративные примеры.
- Пять блокнотов Colab подготовлены для этого курса.
